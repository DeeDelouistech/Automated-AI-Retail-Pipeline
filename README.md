# Automated AI Retail Data Pipeline

## Overview
A secure, automated ETL (Extract, Transform, Load) pipeline designed to modernize automotive inventory management. This project bridges the gap between raw, unstable inventory data and a structured, relational database environment.

## Key Features
* **Secure Data Ingestion:** Automated Python pipeline with strict validation and error logging.
* **Database Architecture:** Relational SQLite schema for data integrity.
* **Security First:** Parameterized SQL queries to prevent SQL injection.
* **AI Integration:** Programmatic use of LLMs to generate high-converting marketing copy from vehicle metadata.

## Technologies Used
* **Languages:** Python, SQL
* **Tools:** SQLite, Git/GitHub, Linux/Bash
* **Concepts:** ETL Pipeline Architecture, PII Data Protection, Version Control

## Project Audit Log
System anomalies and corrupted records are automatically captured in `validation_errors.log` to ensure 100% compliance and data transparency.
